# Skills catalog

Library and domain skills worth installing per stack, from what pocos uses. Workflow skills
(`architect`, `review`, `recover`, `remember`, `imprint`) are generated by the templates and are
not listed here.

## How to install

Prefer the upstream source through the skills CLI, which records a pin in `skills-lock.json`:

```bash
npx skills add <owner/repo>          # interactive: pick skills, target .agents/skills
npx skills --help                    # confirm current flags before scripting it
```

The CLI's flags change; check `--help` rather than trusting this file. If it is unavailable or
offline, copy the skill directory from pocos (`~/apps/personal/pocos/.agents/skills/<name>`) and
then **search the copy for `pocos`/`@pocos` and rewrite those references** to this project's paths
and scope — several pocos copies are project-adapted.

After installing, symlink each into `.claude/skills/` (the scaffold script does this for skills
present at render time; for later installs:
`ln -s ../../.agents/skills/<name> .claude/skills/<name>`), add a bullet to `.agents/README.md`,
and a row to `context/library-docs.md`.

Install only what the confirmed stack uses. A skill for a library you do not use is noise that
agents will still load.
