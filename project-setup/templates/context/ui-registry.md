# UI registry

This index is maintained by `/imprint`. Read the linked pattern for the component you are building;
update that reference and add an index entry for new patterns. Do not load the whole registry.

## How to use

1. Before building a component, check this registry and match existing patterns exactly.
2. After building it, run `/imprint` to record its patterns in `context/ui/<component>.md` and
   add an entry below.
